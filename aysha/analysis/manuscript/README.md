# manuscript/ — what is what

**`manuscript_full_draft.md` is the manuscript.** That is the file to read, edit
and submit from. Everything else here is either an input or an archive.

| File | What it is |
|---|---|
| **`manuscript_full_draft.md`** | **The current manuscript. Use this one.** |
| `manuscript_full_draft_2026-07-31_before_edits.md` | The draft as it stood on 31 July 2026, before the August editing pass. Kept so any change can be diffed against the pre-session state. |
| `literature_positioning.md` | Working note: what the paper contributes against the 21 papers in `../literature`. Not part of the manuscript. |
| `data_analysis_sections.md` | Earlier long-form reduction write-up that the Results were built from. Superseded by the manuscript; kept for reference. |
| `manuscript_v5.docx`, `Supplementary_Material_v3.docx` | The November 2024 versions. Source of the bibliography still to be merged. |
| `_session_backups_2026-08/` | Intermediate snapshots taken between edits during the August pass. Safety copies only — no unique content, nothing to merge. Delete whenever you like. |

To see what the August pass changed:

```
diff manuscript_full_draft_2026-07-31_before_edits.md manuscript_full_draft.md
```
