# Reproduction package — structured SiC volumetric receiver

Everything numerical and graphical in the manuscript is produced by two scripts from the raw
logger files. There are no hand-entered constants and no intermediate manual steps.

## Contents

| Path | Role |
|---|---|
| `receiver_reduction.py` | Single reduction pass: reads raw logs, produces every derived scalar, table and figure input |
| `make_figures.py` | Draws Figures 2–6 from the archived outputs |
| `../RAW/*.csv` | Raw logger files, one per run (unmodified instrument output, latin-1 encoded) |
| `outputs/` | All archived results (regenerated by the scripts; committed for reference) |
| `figures/` | Figures 2–6 as PNG |
| `manuscript_revised_v2.md` | Manuscript |
| `review_response_v*.md` | Review correspondence |

Figure 1 is a drawn schematic of the apparatus and sensor positions. It is the only figure not
produced by the pipeline, and it contains no data.

## Reproducing everything

```
python receiver_reduction.py --raw ../RAW --out outputs --nmc 4000
python make_figures.py
```

Runtime is roughly seven minutes for the reduction, dominated by the two 4000-realization Monte
Carlo passes and the multi-start profile fits, and a few seconds for the figures. Reduce `--nmc`
for a fast check; the point estimates do not depend on it. Requirements: Python 3.11 with numpy,
pandas, scipy and matplotlib.

Both scripts are deterministic. Every stochastic step is seeded (`monte_carlo(seed=20260902)`,
`fixed_profile_test(seed=20260904)`), so a rerun reproduces the archived outputs bit for bit.

| `table1_envelope.md`, `table2_constants.md` | Manuscript tables, generated |

Keys inside `results.json` worth naming, since they carry the paper's structural argument:

- `nusselt` — pooled and grouped (common-slope, per-configuration-prefactor) correlations, the
  square-duct references from Shah and London, and the inverse-Graetz exit coordinate
- `ntu_profile` — profile-corrected transfer units per run, their pooled and grouped exponents,
  the outlet-bias band, and the ratio to the isothermal-wall identity
- `ntu_structure` — the isothermal-wall exponent, and the requirement `d ln N / d ln Re` evaluated
  on the measured properties for a fixed Nusselt number and for a temperature-independent conductance
- `fixed_profile_test` — the falsification of §4.2, three families (shared `h(z)` at 2/3/5/7 nodes,
  shared `Nu(z)` at 3/5, per-configuration `h(z)` at 5), each with fitted nodes, rms and maximum
  outlet residual, the residual regression on ln Re, and the per-run residuals with their run ids
- `wall_extrapolation` — exponent under each admissible reconstruction of the unmeasured front
  11 mm and rear 30 mm, and the runs for which a full linear rear continuation is inadmissible
- `identification` — the four capacitance/loss determinations plus the primary matched-effectiveness
  one, with `COOL_PROVENANCE` fixing which heating run each cooling transient decays from
- `controller_correlation_bounds` — every Monte Carlo quantity in both controller-correlation limits
- `delivered_power`, `similarity`, `sensor_selection_swing`, `monolith`, `envelope`

## Conventions the reader should know before using the numbers

`Re` is nominal: formed on the metered flow divided equally among the hundred channels, which is
the assumption §5.2 and §5.3 argue is violated. Nusselt numbers and conductances are likewise
apparent, referred to the length-averaged side-wall temperature under the quadrature weights in
`WTS`. These are the correct objects for the paper's arguments and are not validated transport
coefficients; §5.1 quantifies how far they move when the reference probe is changed.

Uncertainties come in two kinds and are never mixed. Instrumental terms are Monte Carlo standard
deviations over the propagated instrument model. Regression standard errors describe the scatter of
runs about a fitted law. For the correlations of §4.2 the regression term is the larger by an order
of magnitude and is the one to read as the uncertainty of the correlation.

The four mass-flow controllers are propagated as four persistent per-unit errors drawn once per
realization and combined with each record's own measured shares, so a single physical unit error
reaches every steady and transient record with weights that differ only because the shares do.
Because the manufacturer states no correlation between units, every instrumental term is computed
twice — fully correlated and independent — and both are archived.

## Known limitations of the package

The raw files are the instrument's own output and include channels not used here. The heating
eigenvalues are reported under two sensor rules because the earlier analysis chain applied a rule
different from the one its header documented; both are archived rather than one being chosen
silently. The installed differential-pressure channel is retained in the outputs although §4.7
shows it cannot resolve the monolith pressure drop, because the null result is what motivates the
measurement recommended in §5.3.

## Software stack of the archived run

Python 3.11.16, NumPy 2.4.6, SciPy 1.17.1, pandas 2.3.3, Matplotlib 3.11.1.
Both scripts are seeded. The multi-start optimizer in `fixed_profile_test`
is the one step whose last digits may differ across BLAS builds; its
reported statistics are stable well beyond the digits quoted.
