# Academic and Technical Critique of `1D_v49`

**Date:** 2026-09-02  
**Scope:** `1D_v49.jl`, `run_1D_v49.jl`, `test/smoke_1D_v49.jl`, `summaries/theory_1D_v49.md`, the v49 entry in `summaries/journal.1D.md`, all saved files under `summaries/1D_v49/`, and relevant lessons from the mature 1D/2D journals and manuscript-readiness reviews.

## Executive assessment

Version 49 is not a validated resolution of the flow-rate problem. Its saved numerical results are reproducible, all smoke tests pass, the primary solid/gas model closes its programmed energy ledger, and aggregate temperature errors improve slightly relative to v48. However, the central v49 additions were not active in the saved calibration:

1. the intended flow-slope penalty is removed from execution by a later duplicate definition of `loss_cases_v49`;
2. the dormant slope function is itself non-executable as written;
3. the five new observation parameters (`p[24:28]`) do not influence the state equations, reported observations, or objective; and
4. several widened optimizer bounds are contradicted by narrower clamps in the active parameter accessors.

Numerical perturbation confirms that changing all five new observation parameters produces exactly zero change in the E67 output matrix and exactly zero change in the full calibration objective. Consequently, the v49 results do not test the documented thermocouple-observation hypothesis, and the fitted values of parameters 24--28 have no inferential meaning.

The user's interpretation of the flow-rate deviation is well supported: the discrepancy is systematic within each irradiance cluster. All 21 exported model-minus-experiment flow-slope errors are negative. For the downstream signals, residual-versus-flow regressions commonly have $R^2=0.72$--$0.97$, with the model underpredicting temperatures at high flow and overpredicting them at low flow. This is a coherent model-discrepancy pattern, not ordinary zero-mean measurement scatter. It strongly indicates a missing or incorrectly represented flow-dependent transport/observation mechanism. It does not, by itself, uniquely identify which mechanism is missing.

The most defensible current role for v49 is therefore a diagnostic baseline. It is not suitable for publishing extracted convective, radiative, or conductive coefficients as validated physical properties.

## 1. Audit completeness and reproducibility

The saved v49 output tree contains 55 non-empty artifacts:

- 20 CSV files;
- 34 PNG files: 18 transient plots, 15 axial-profile plots, and one steady parity plot; and
- one optimization-summary text file.

The main tabular outputs have the expected coverage: 126 transient-metric rows (18 cases times seven signals), 15 heating steady-result rows, 21 flow-slope rows, 28 parameter rows, two invariant rows, and 15 cell-diagnostic files. No zero-byte output was found.

The saved parameter vector reproduces

```text
calibration_loss_v49(pnew_v49; nodes=15) = 1.71334559737503
```

which equals the saved objective to printed precision. The optimization summary nevertheless reports `return_code=MaxIters`. The journal statement that the calibration "converged" after 1,177 evaluations is therefore not supported by the authoritative optimization output.

The smoke suite passes 21/21 programmed checks:

- basic parameter and geometry checks: 10/10;
- E67 forward and energy checks: 5/5;
- mesh checks: 2/2; and
- C69/C80 cooling checks: 4/4.

These are execution and bookkeeping checks, not model-validation gates. There are no tests for flow-slope agreement, observation-parameter sensitivity, parameter identifiability, wall-inversion fidelity, residual randomness, or held-out predictive performance. C81 is exported but is not exercised by the smoke test.

## 2. Critical implementation failures

### 2.1 The flow-slope loss is not part of the active objective

`1D_v49.jl:882-915` defines `loss_flow_slopes_v49`, and the first `loss_cases_v49` definition at lines 917--943 attempts to add it. A second method with the same positional signature is defined at lines 962--993. In Julia, keyword names and defaults do not create a different dispatch signature, so the second definition replaces the first. Runtime method inspection shows only:

```text
loss_cases_v49(p, keys; is_cooling, nodes) @ 1D_v49.jl:962
```

The active method never calls `loss_flow_slopes_v49`. Both `calibration_loss_v49` and `calibrate_v49` call this later method, so neither uses the advertised multi-objective slope regularization.

The dormant implementation also contains independent defects:

- line 923 expects four returned values from `solve_case_v49`, which returns three;
- it calls undefined or stale helpers `loss_single_case_v49` and `ordering_penalty_v49`; and
- line 893 indexes `cond_dict[flow]`, but `flow` is undefined; the rest of the code uses `qlpm`.

Thus simply removing the duplicate method would not activate a valid slope loss.

Using the exported v49 slope residuals and the normalizations declared in the dormant function gives an intended slope penalty of approximately **11.0145**. This is more than six times the complete reported objective of 1.71335. The saved parameter vector is therefore qualitatively incompatible with the assertion that the stated unit-weight slope penalty was included.

### 2.2 All five new observation parameters are inactive

The documented parameters are:

```text
p[24] h_probe_ref
p[25] w_probe_rad
p[26] G_probe_stem
p[27] w10_stem
p[28] w11_stem
```

However, the active T3 ODE at `1D_v49.jl:516-530` uses hard-coded values:

```julia
h_tc = 40.0 * (flow_lpm / 15.0)^0.60
Q_conv_sensor = h_tc * 1.0e-5 * (T_gas_sensor - T3_sensor)
Q_rad_sensor = 0.85 * sigma_sb_v49 * 1.0e-5 * (T_tube_sensor^4 - T3_sensor^4)
```

It does not use `h_probe_ref`, `w_probe_rad`, `G_probe_stem`, or the declared `T3_PROBE_AREA_v49=5.0e-5 m2`. There is no stem-conduction term. Natural cooling uses a hard-coded 8 W/m2-K, whereas the theory document specifies 4 W/m2-K.

Likewise, `extract_outputs_v49` at lines 750--759 returns raw `core_at_v49` and `perim_at_v49` values for T10 and T11. It never applies `w10_stem` or `w11_stem`.

A direct numerical sensitivity test gave:

```text
max |outputs_E67(p24:28 changed) - outputs_E67(baseline)| = 0.0 K
delta calibration loss for each of p24, p25, p26, p27, p28 = 0.0
```

These are exact flat directions. Their printed "calibrated" values are optimizer coordinates without physical content. The five extra dimensions likely also contributed to termination at `MaxIters`.

### 2.3 Optimizer bounds and active physics bounds disagree

Several bounds advertised as expanded are silently narrowed by accessors:

| Parameter | optimization bounds | active accessor clamp | saved value | effective value |
|---|---:|---:|---:|---:|
| `G_core_perim` | 0.1--100 W/m-K | 0.1--50 | 53.971 | 50.0 |
| `flange_scale` | 0.05--20 | 0.05--5 | 5.1247 | 5.0 |
| `G_rear_tube` | 0.01--15 W/K | 0.01--10 | 6.828 | 6.828 |
| `h_suction` | 0--150 W/m2-K | 10--150 | 9.712 | 10.0 |

At least three saved coordinates are in flat clipped regions. The theory table reports the raw optimizer coordinates rather than the values actually used by the equations. The journal claim that the widened bounds were physically explored is therefore false for these coordinates.

### 2.4 The observation energy balance is one-way

The T3 node receives convective and radiative heat in its ODE, but equal and opposite terms are not removed from the gas and tube equations. Its stored energy is also omitted from `compute_energy_balance_v49`. Machine-zero closure therefore validates the programmed plant ledger only; it does not validate conservation of the documented plant-plus-probe system. The omission is numerically small for the hard-coded probe area but conceptually important because exact conservation is presented as evidence for the complete formulation.

## 4. The flow-rate discrepancy is demonstrably systematic

For every sensor and all three power groups, the exported slope error

$$
\Delta b = \left(\frac{\partial T}{\partial \dot V}\right)_{model}
-\left(\frac{\partial T}{\partial \dot V}\right)_{experiment}
$$

is negative. The model invariably predicts a stronger temperature decrease with increasing flow than is observed.

The clearest downstream examples are:

| Power | signal | experimental slope | model slope | slope error | residual-vs-flow R2 |
|---:|---|---:|---:|---:|---:|
| 456 kW/m2 | T11 | -1.37 | -20.12 | -18.75 | 0.954 |
| 456 kW/m2 | T10 | -3.54 | -19.31 | -15.77 | 0.945 |
| 456 kW/m2 | T3 | +0.54 | -16.14 | -16.68 | 0.969 |
| 304 kW/m2 | T11 | -1.93 | -15.67 | -13.74 | 0.856 |
| 304 kW/m2 | T10 | -3.68 | -14.99 | -11.31 | 0.833 |
| 304 kW/m2 | T3 | -0.13 | -12.05 | -11.92 | 0.873 |
| 256 kW/m2 | T11 | -5.17 | -11.72 | -6.55 | 0.778 |
| 256 kW/m2 | T10 | -6.15 | -11.09 | -4.94 | 0.718 |
| 256 kW/m2 | T3 | -3.04 | -8.43 | -5.39 | 0.754 |

At 456 kW/m2, the T3 endpoint residual moves from +73.6 K at 7.13 LPM to -67.0 K at 15.28 LPM. At 304 kW/m2 it moves from +97.5 K at 4.53 LPM to -76.6 K at 18.71 LPM. Similar sign-changing, nearly monotone rotations occur in T10 and T11. The optimizer approximately centers some cluster residuals near zero while failing their slopes; an aggregate RMSE can conceal this failure.

The pattern is spatially informative:

- T8 retains substantial experimental flow sensitivity and is comparatively close at 456 kW/m2.
- T2 slope errors are only 0.20--0.76 K/LPM.
- the largest systematic failures occur at downstream solid/perimeter stations and T3.

This localizes the main discrepancy to axial/rear transport and observation, rather than to a single global temperature offset. The reduction of downstream slope errors with power also suggests temperature-dependent redistribution (radiation, contact/conduction, or spatial flow participation), although different flow ranges and transient durations prevent a unique inference.

## 5. Why the current model structurally overpredicts flow sensitivity

### 5.1 Single-stream coupling forces every flow increment through the hot domain

The v49 gas model sends 100% of the measured mass flow through one representative channel population. Increasing flow simultaneously increases mass throughput, Reynolds/Graetz number, local HTC, and downstream enthalpy transport in every cell. There is no degree of freedom for incremental flow to pass through cooler peripheral channels, gaps, an annular leakage route, a partially blocked manifold, or other paths that couple weakly to the thermocouples.

The experiment instead has the signature of spatially selective coupling: the front responds strongly to flow while deep locations change little. A minimum plausible explanation is that the fraction and spatial distribution of flow participating in the measured hot path varies with total flow, temperature, or pressure drop. This need not mean an unconstrained scalar bypass. The earlier 1D dynamic-bypass and 2D common-pressure studies show that a simple bypass can conflict with cooling and is not uniquely identifiable. A physically constrained multi-path model tied to pressure-drop data is required.

### 5.2 The fitted optical source is effectively a surface source

With `front_dep=0.4529` and `beta_opt=274.5 1/m`, the continuous source deposits approximately:

- 58.4% within 1 mm;
- 76.0% within 3 mm;
- 86.1% within 5 mm; and
- 97.3% within 11 mm.

At the calibration grid, 95.5% of core source power is placed in the first 9.13 mm cell. At N=25 the first-cell fraction is 87.8%, and at N=50 it is 74.2%. This is a mesh-dependent representation of a nearly surface-heated receiver. Downstream temperatures must then be maintained by gas transport, axial conduction, or the rear rail. If the real channel optics transport radiation deeper through reflection, participating-media effects, or nonuniform illumination, the present source law will inevitably over-couple downstream behavior to the flow-cooled front region.

The cell diagnostics show the consequence. At N=25, 21--24 of 25 cells have negative local `Qgas`: gas heated near the front subsequently transfers heat back to cooler downstream solid. For E67, net core gas heat is +126.8 W while negative downstream cells sum to -61.1 W. The result is not a conventional monotone wall-to-gas exchanger but a front heater followed by gas-to-solid regeneration.

### 5.3 The proposed probe explanation was not implemented—and is not sufficient by itself

The documented hypothesis that radiation pins T3 at low flow is reasonable to test, but the saved run did not use the fitted probe parameters. Under the active hard-coded ODE, representative endpoint balances show convection and radiation of comparable magnitude rather than low-flow radiation dominance:

| Case | flow | receiver-exit gas | first tube wall | T3 | convective term | radiative term |
|---|---:|---:|---:|---:|---:|---:|
| E67 | 15.28 LPM | 710 K | 688 K | 696 K | +5.63 mW | -5.50 mW |
| E71 | 7.13 LPM | 846 K | 823 K | 827 K | +4.88 mW | -4.76 mW |
| E76 | 4.53 LPM | 762 K | 740 K | 745 K | +3.40 mW | -3.27 mW |

Radiation cools the junction toward a tube wall colder than the calculated gas; it does not supply an independent hot rear boundary. The observer remains slaved between two plant states that both have excessive flow dependence. A sensor model cannot repair incorrect plant transport unless it is independently constrained and connected to the correct local gas/wall state.

### 5.4 Rear hardware and sensor geometry remain under-resolved

The v49 rear rail, alumina tube, water flange, and sensors are still compressed into one-dimensional effective paths. The older setup record in `analysis/background/1D_v8_theory_manual.md` specifies a 150 mm rear tube, 75 mm cavity radius, 57 mm insulation radius, 77.6 mm adaptor, 6.5 mm gas radius, and 1.5 mm tube wall, whereas v49 uses a 63 mm tube, 25/30 mm felt/case radii, and 7/11 mm tube radii. Unless a later metrology record explicitly supersedes the older dimensions, rear heat-loss and probe-transfer interpretations lack geometric provenance.

T10 and T11 algebraic temperature blends are also not rigorous sensor models. A thermocouple affected by sheath/stem transfer should normally have a finite-capacity balance with contact, stem, and possibly radiation conductances. A dimensionless instantaneous blend can be a useful observation surrogate, but its weights should not be described as identified physical conductances.

### 5.5 Systematic experimental covariates must still be excluded

The systematic residuals establish model discrepancy but do not prove a unique omitted mechanism. Three data-reduction issues remain capable of producing or amplifying apparent flow slopes:

1. **Nominal versus actual absorbed power.** One fixed power multiplier is used for every case in each nominal irradiance group. If lamp/mirror output or absorptance drifted with run order, and run order covaries with flow, part of the apparent flow trend is actually unrecorded input-power variation.
2. **Endpoints are not steady states.** The exported endpoint storage rate is 9.5--13.2% of delivered power at 456 kW/m2, 11.4--15.2% at 304 kW/m2, and 11.7--18.1% at 256 kW/m2. Calling these rows and slopes "steady" is not justified.
3. **Flow metrology and standard-state convention.** The code assumes the recorded LPM is standard volumetric flow and converts it with one fixed standard density. The MFC reporting convention, calibration uncertainty, leak tightness, and pressure/temperature reference should be verified. A simple global scale error is unlikely to explain why T2 is good while downstream signals fail, but it should be ruled out.

The proper conclusion is therefore: **the error is systematic and structural with respect to the current model/data interface, while the available measurements do not uniquely separate flow distribution, optical/rear transport, sensor transfer, and unmeasured input drift.**

## 6. Further scientific limitations

### 6.1 The reported LMTD coefficient is not rigorous for the calculated temperature field

`macroscopic_htc_v49` forces both endpoint driving differences to at least 0.1 K before applying the LMTD formula. In every N=25 heating diagnostic, the raw downstream difference `Tcore,last - Tgas,out` is negative (-0.33 to -2.72 K), and most downstream cells transfer heat from gas back to solid. A standard same-sign LMTD is not defined for a temperature crossing. Replacing the negative endpoint with 0.1 K creates a finite but convention-dependent coefficient.

The 11.38% change in reported HTC between N=15 and N=50 is therefore not a proof of grid independence. The smoke test merely accepts changes below 15%. This is too loose for the study's coefficient-extraction objective and is partly driven by the mesh-dependent first-cell source allocation.

### 6.2 Line-of-sight radiation remains negligible

The fitted `F_LoS=0.00394` produces only about 0.006--0.200 W in representative cases, compared with 103--222 W delivered power. It cannot provide the missing downstream thermal floor or explain the flow-slope discrepancy. It may be retained for completeness, but it should not be presented as an important resolved transport pathway.

### 6.3 Capacity agreement is imposed, not independently validated

The 301.11 J/K total is directly encouraged by the capacity regularization term, while both perimeter and rear effective capacities are fitted. Agreement with 301 +/- 23 J/K is therefore a constrained calibration outcome, not independent validation. Profile likelihoods or cooling-only identification would be required before interpreting the split capacities physically.

### 6.4 Cooling is conditional rather than blind validation

Cooling simulations initialize core and perimeter profiles directly from measured T8/T12/T11/T9/T10, initialize the rear states from those profiles and T3, and then overwrite the first seven reported output values with the measured first row. The forced replacement does not change the hidden ODE states, producing visible initial jumps in the cooling plots. Cooling can still test conditional decay dynamics, but it is not an independent prediction from operating conditions alone.

### 6.5 Parameter identifiability is not demonstrated

The fit contains exact flat dimensions, clipped coordinates, an optimizer stopped at `MaxIters`, highly correlated optical/conductive/loss mechanisms, and no multi-start, profile-likelihood, bootstrap, or covariance analysis. The mature 2D journal already found that receiver `UA(Re)` and a T3 observer are structurally non-identifiable with the present outlet information. V49 provides no new evidence that overturns that result.

## 7. Ranked recommendations

### Rank 1 — Repair and verify the v49 implementation before any further physical interpretation

Remove the duplicate loss function and implement one explicit objective. Correct the `solve_case_v49` return arity and `qlpm` indexing. Wire parameters 24--26 into the T3 balance and parameters 27--28 into explicit observation operators. Make accessor clamps identical to exported optimization bounds. Add tests requiring:

- each fitted parameter to change at least one relevant output and the objective under a finite perturbation;
- the full objective to equal base transient loss plus the independently recomputed slope term and regularizers;
- reported parameter values to equal effective values used by the equations; and
- failure if the slope penalty is accidentally omitted.

Until these tests pass, do not spend computation on another full calibration.

### Rank 2 — Re-run a clean, converged calibration and report objective decomposition

Start from multiple dispersed initial points after removing inactive dimensions. Save the base temperature loss, gradient/shape loss, ordering loss, flow-slope loss, capacity regularization, and power regularization separately. Treat `MaxIters`/`MaxTime` as non-convergence. Require consistent solutions across starts before interpreting parameters.

### Rank 3 — Quantify the experimental flow trend with a proper within-power statistical model

Replace single endpoints by final-window means or fitted asymptotes, and attach uncertainty to every slope. Within each power cluster, regress temperature on measured flow while controlling for actual irradiance, inlet temperature, ambient temperature, run order, initial state, and remaining time derivative. Inspect residual autocorrelation and heteroscedasticity. This will determine how much of the systematic pattern survives correction for non-steady endpoints and input drift.

### Rank 4 — Obtain an independent outlet enthalpy constraint

The highest-value experiment is an independent mass-averaged outlet enthalpy measurement: downstream mixing chamber plus shielded temperature measurement, or direct gas calorimetry. Add a tube-wall thermocouple near T3 and document probe diameter, position, emissivity, orientation, exposed length, and stem path. Fit the plant without T3, then identify/validate the observation operator separately. Without this, bulk exit gas, probe bias, and `UA(Re)` remain confounded.

### Rank 5 — Test a minimum physically constrained multi-path flow model

Introduce at least two conservative flow populations (for example hot illuminated channels and cooler peripheral/leakage paths) with a common pressure-drop relation and exact total mass conservation. Constrain hydraulic areas and resistance using DP data and geometry. The measured signal should sample the appropriate local path, while mixed outlet enthalpy is computed by mass-weighted enthalpy. Do not revive an unconstrained scalar bypass: past 1D/2D work shows it can trade heating fit against cooling failure without identifying real flow distribution.

### Rank 6 — Replace the mesh-dependent front source with independently constrained optical transport

Represent direct front-face absorption as a physical boundary flux rather than depositing it into the first finite volume. Use ray tracing, optical attenuation measurements, or a bounded multi-band source kernel to constrain penetration through the square channels. Test whether deeper irradiation or distributed wall-to-wall radiation can reproduce rear flow invariance without corrupting front temperatures and energy closure.

### Rank 7 — Build a geometry-faithful rear hardware and sensor submodel

Resolve the documented tube/adaptor/flange lengths and radii, contact areas, water-cooled length, and sensor coordinates. Model T10/T11/T3 with finite-capacity junction balances and independently bounded stem/contact conductances. Use cooling data to constrain hardware and sensor time constants before using heating data to infer receiver coefficients.

### Rank 8 — Redefine the reported macroscopic heat-transfer quantity

Do not use a clamped endpoint LMTD when local driving temperature changes sign. Report local `h(z)`, signed cell heat rates, integrated `UA`, and net enthalpy transfer separately. If a single effective coefficient is needed, define it through a documented integral or forward-response equivalence and demonstrate convergence to 2--5% over N=25/50/100 with a mesh-independent source boundary.

### Rank 9 — Perform formal identifiability and held-out validation

Profile the Nusselt parameters, optical depth, rear conductances, and sensor parameters individually and jointly. Use power-group or flow-level holdouts rather than only cooling initialized from measured profiles. Report confidence intervals and parameter correlations. If no interior basin exists, retain a directly measured apparent correlation and state non-identifiability rather than assigning precise physical coefficients.

### Rank 10 — Synchronize documentation and acceptance gates

Generate theory/journal metric tables from the saved CSVs. Replace "resolved," "converged," "grid-independent," and "out-of-sample" with conditional language until the relevant gates pass. Expand the invariant CSV to include mesh convergence, parameter activity, slope error, endpoint storage fraction, source-depth invariance, observation energy accounting, wall/inversion signs, and optimization termination.

## 8. Recommended immediate v50 decision sequence

1. Make a minimal implementation-only repair; do not add more physics simultaneously.
2. Run unit sensitivity tests proving every intended parameter and loss term is active.
3. Recompute the v49 baseline with the corrected slope term and inspect whether a physically bounded optimum exists.
4. Re-estimate experimental within-power slopes from final windows/asymptotes with covariate checks.
5. If the corrected single-stream model still produces the same residual rotation, treat the single-stream architecture as falsified for rear-flow sensitivity and test the constrained two-path model.
6. Only after plant observability is improved should Nusselt/Rosseland parameters be presented as extracted coefficients.

## Final verdict

V49 makes essentially no demonstrated progress on the central flow-rate problem because its proposed slope regularization and fitted observation models are inactive. The saved results instead strengthen the diagnosis that the current single-stream, front-loaded, one-dimensional plant has a structural discrepancy: it cools downstream states too strongly as flow increases, at every power level and for every reported signal. The systematic nature of the deviation is real and scientifically important. The next step is not another higher-dimensional calibration of the present code; it is first an implementation repair, then a discriminating experiment/model comparison capable of separating flow distribution, optical/rear transport, and sensor observation physics.
